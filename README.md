# Cold & Close

Statický český web pro klientský náhled na GitHub Pages. Bez sestavování, externích knihoven, cookies a analytiky.

## Spuštění

Otevřete `index.html` nebo použijte lokální HTTP server. GitHub Pages publikují kořen větve `main`.

## Podklady a vizuální identita

Obsah vychází z dodaného `cold-close_zadani.jpg`. Logo je z dodaného archivu `LOGO_DIGITAL.zip`, oříznuté pouze o prázdné okraje. Barvy odečtené z originálních PNG: tmavě modrá `#103348`, světle modrá `#76CADF`. Světlejší plochy a tmavší textové akcenty jsou doplňkové odstíny. Samostatný textový logo manuál nebyl mezi podklady.

## Formulář

Formulář validuje povinné údaje a připravuje `mailto:` zprávu na adresu ze zadání. Nic neposílá automaticky a neukládá osobní údaje. Návštěvník musí zprávu odeslat ze své e-mailové aplikace. Pro přímé odesílání je potřeba samostatně nakonfigurovat formulářovou službu a doplnit údaje správce i pravidla zpracování dat. Telefon a e-mail jsou převzaty ze zadání; identita právního provozovatele a IČO nebyly dodány.

Před finálním ostrým spuštěním má klient potvrdit texty, kontakty a doplnit identifikační údaje provozovatele. Náhled neobsahuje smyšlené reference, výsledky ani klientská loga.
